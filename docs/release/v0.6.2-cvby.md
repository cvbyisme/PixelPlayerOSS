# v0.6.2-cvby

基于 PixelPlayerOSS 的个人修改版，本版重点是设置分组重构与音频 offload 开关。

## 新增

- 设置里新增 **「cvby 自定义」** 页面：开屏启动动画、音乐库背景色、点击封面开歌词、播控按键样式与形状、音频引擎、联网功能开关，全部集中在一处
- **「DSP 按需挂载（硬件 offload）」** 变成真正的开关（设置 → cvby 自定义 → 音频引擎，默认开启）

## 行为变化

- 硬件 offload、Hi-Res 采样率上限、环绕下混三者**互斥**：开启其中一个会自动关闭另外两个，不会再出现开关亮着却没生效的情况
- 关闭 offload 后回退到 CPU 侧 float PCM 通路（兼容性更好，耗电略高）
- offload 仅在「输出模式 = 系统默认」且音频链路上没有额外 DSP 处理器时生效

## 其它

- 关于页新增一段 offload 说明，写清作用与何时该关掉
- 设置搜索已收录 cvby 自定义页的全部条目

## 安装

- `arm64-v8a`：绝大多数现代手机
- `armeabi-v7a`：老 32 位设备
- 签名与以往版本一致，可直接覆盖安装
