# v0.7.0-cvby

基于 PixelPlayerOSS 的个人修改版。这一版主要在音频链路：把「实际在放什么」显示准确，让音量能真正细调，并修掉一批播放相关的问题。

## 新增

- **音质徽章**：播放页显示当前输出的采样率、位深，以及走的是 Direct 还是 Mixer 通路
- **音量细调面板**：点播放页的音量数字打开，按系统真实档位（`STREAM_MUSIC` 的 min/max）吸附拖动，另有单步加减、静音和「第 N / 总档」显示
- **高音质模式开关**：放在音频输出页，可随时切换

## 修复

- **徽章不再谎报采样率**：之前放 96 kHz 的歌会显示「→ 384 kHz」，看着像升频，其实输出一直是源采样率。根因是 DAC 回执的最高档位被当成了输出率
- **播放中切换输出设备不生效**：补上 `AudioDeviceCallback`，设备增删时重建输出
- **歌曲结尾残留**：修掉 `queueEndOfStream` 后尾部残帧未消费的问题
- **自定义背景图偶发丢失**：修正 staging 写入时序
- **背景图内存占用偏高**：Coil 请求加 `size()` 限制解码尺寸
- **并发竞争**：`HiFiCapabilityChecker` 加 `@Synchronized`

## 变化

- **音质读数从播放页移到「音频输出」二级页**：播放页不再拥挤，读数放进输出设备页顶部的音质卡片
- **降采样改用一阶 IIR 抗混叠低通**（通带比 0.45）：不再直接丢样本，减少高频折叠失真
- 清理 12 条重复 import

## 其它

- 版本号 `0.7.0-cvby`（code 1100007）
- 版本号从 11 跳到 1100007 的原因：alpha 构建用的号段是 `BASE × 100000 + run_number`，`0.7.0` 的 alpha 已经占了 1100006，正式版必须高于它才能直接覆盖安装

## 安装

- `arm64-v8a`：绝大多数现代手机
- `armeabi-v7a`：老 32 位设备
- 签名与以往版本一致，可直接覆盖安装，设置与曲库保留

## 注意

- 播放中切换「高音质模式」会重建播放器，当前播放会有一瞬间中断
- 徽章上的 `Direct` / `Mixer` / `HW` / `SW` 在中文界面下仍是英文
