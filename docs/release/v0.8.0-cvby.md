# v0.8.0-cvby

基于 PixelPlayerOSS 的个人修改版。这一版是**把上游 101 个提交合并进来**：原版功能不再落后于个人定制，所有 cvby 专属开关原样保留。

## 合并规模

- 上游 `upstream/main`（PixelPlayerHQ/PixelPlayerOSS）101 个提交，79 个是实际改动，其余为合并提交
- 21 处冲突全部手动融合：CVBY 设置分类与上游 EQUALIZER 分类并存、自定义背景/图标与上游「界面外观」并存、DSP 按需挂载与上游均衡器/蓝牙 offload 判断并存

## 新增（来自上游）

- **bit-perfect USB 输出**（实验性）：USB DAC 直出，绕过系统混音
- **均衡器改为软件 DSP**（替换系统 audiofx）：更好找更好开，保存的预设开播自动套用，采样率变化时增益立即跟新
- **首页「最近添加」板块**，支持长按菜单、右滑加入队列；每日 Mix 逐天轮换
- **Jellyfin 收藏双向同步**；云曲库整库入队、导出离线副本（支持断点续传）
- **折叠屏双栏自适应布局**、横屏播放大图适配、胶囊形迷你播放器
- **系统字体开关 + 界面缩放**（「界面外观」）
- 巴西葡语、捷克语、斯洛伐克语、越南语翻译

## 修复（来自上游）

- 手机导航栏绘制在播放器面板之上（原 navbar 崩溃 #272）
- 蓝牙切歌更稳，session IPC 移出主线程
- 歌曲库单事务读取，清空队列改区间删除，移除 shuffle 的 60 首上限
- 第三方键盘收起后元数据编辑页留白
- 歌词行布局/自动滚动/定位按钮显示条件
- RTL 下上一首下一首顺序、进度条拇指位置
- 封面按尺寸请求（Jellyfin/Navidrome），失败回退专辑封面
- Subsonic 非纯字母数字 id 可播，兼容旧 Navidrome URI、文件名中的 `+` 号

## 保留的 cvby 定制

cvby 自定义分类页、自定义背景（模糊/暗化/不透明度）、应用图标选择（原版/动漫风）、开屏动画开关、点击封面打开歌词、音乐库背景色、播控按键样式与形状、本地优先网络开关、**DSP 按需挂载 + Hi-Res 采样率上限 + 环绕下混三者双向互斥**

## 其它

- 版本号 `0.8.0-cvby`（code 1200100）
- 版本码为什么是 1200100：alpha 构建用 `CODE × 100000 + run_number`，0.8.0 的 alpha 已用到 1200008，正式版必须更高才能直接覆盖安装
- 动漫图标本次仍为旧版，等的下一轮再换新图

## 安装

- `arm64-v8a`：绝大多数现代手机
- `armeabi-v7a`：老 32 位设备
- 签名与以往版本一致，可直接覆盖安装；设置与曲库保留

## 注意

- 首次打开可能因曲库整事务读取做一次较慢的初始化
- 播放中切换「高音质模式」或 DSP 相关开关会重建播放器，当前播放有瞬间中断
