# v0.6.3-cvby

基于 PixelPlayerOSS 的个人修改版。这一版把「个人改动」彻底收进一处，并加了可选的应用图标。

## 新增

- **应用图标可选**：设置 → cvby 自定义 → 外观与播控 → 应用图标，`原版` / `动漫风` 二选一（默认原版，老用户升级后图标不变）
- 实现方式是 manifest 里两个 `activity-alias`，切换时只启用其中一个，桌面永远只有一个入口

## 设置结构

- **「自定义背景」整段搬进 cvby 自定义页**：开关、从相册选图、模糊 0–40、暗化 0–85%、页面背景不透明度、卡片/面板不透明度、清除背景
- **播放页外观也在 cvby 页**：模糊封面背景、播放页背景蒙版（0–85%）与点击封面行为、播控按键样式/形状放在同一段
- 上游的「外观」「播放」页面回到接近原版的样子，只保留上游自己的条目

## 其它

- 设置搜索补全了 cvby 专属项：自定义背景、模糊/暗化/不透明度、模糊封面背景、蒙版、应用图标
- 版本号 `0.6.3-cvby`（code 9）

## 安装

- `arm64-v8a`：绝大多数现代手机
- `armeabi-v7a`：老 32 位设备
- 签名与以往版本一致，可直接覆盖安装

## 注意

- 切换图标后部分桌面需要重新绘制（或重启桌面）才会刷新；播放不会被中断
- 模糊相关效果依赖 RenderEffect，需要 Android 12（API 31）及以上
